# Webster's 1828 Dictionary Data

Dictionary entries are sourced from [sktzofrenic/webster1828](https://github.com/sktzofrenic/webster1828) (MIT license).

The underlying text is Noah Webster's *American Dictionary of the English Language* (1828), which is in the public domain.

`dictionary.json` (~24 MB) is **tracked in git** at this path. If the file is missing locally:

```bash
git checkout HEAD -- extras/websters1828/dictionary.json
# or: ./scripts/restore-bundled-extras.sh
```
